# Portfolio_website
My personal portfolio showcasing my skills, and experience.

 PROJECT PREVIEW 

This project is my personal portfolio website developed using HTML, CSS, and JavaScript. It showcases who I am, the skills I have learned, and provides visitors with a way to contact me.

---

FEATURES 

● Welcome Section

- Displays a welcome heading.
- Shows my profile photo.
- Includes a short introduction about myself.

●About Me

Provides information about:

- My journey into web development.
- My inspiration to pursue programming.
- My experience with Code Blossom.
- My career goals.

● Skills Section

Displays my current technical skills including:

- HTML
- CSS
- JavaScript
- Python

●Contact Form

The portfolio contains a contact form where visitors can enter:

- Name
- Email
- Message

The form performs client-side validation by checking:

- Name is not empty.
- Email contains a valid format.
- Message contains enough characters.

If all fields are valid, a success message is displayed.

●Dark Mode

Users can switch between:

- Light Mode
- Dark Mode

This improves accessibility and provides a better viewing experience.

● Dynamic Greeting

A greeting changes automatically depending on the user's current time:

- Good Morning
- Good Afternoon
- Good Evening

● Social Links

Visitors can access my professional profiles directly:

- LinkedIn
- GitHub

 JAVASCRIPT CONCEPTS IMPLEMENTED

This project demonstrates several JavaScript concepts learned during the course:

1. DOM Manipulation

Used to:

- Change text dynamically.
- Create new list items.
- Update page content.
- Show success messages.

Examples:

- "getElementById()"
- "createElement()"
- "appendChild()"
- "textContent"

---

2. Event Listeners

Used to respond to user actions such as:

- Button clicks
- Form submission

Examples:

- "click"
- "submit"

---

3. Conditional Statements

Used to:

- Display greetings based on time.
- Validate form fields.
- Change button text in Dark Mode.

Examples:

- "if"
- "else if"
- "else"

---

4. Form Validation

Checks whether:

- Required fields are completed.
- Email format is valid.
- Message length meets the minimum requirement.

---

5. String Methods

The project uses:

- "trim()"
- "includes()"

to clean user input and validate data.

---

6. CSS Class Manipulation

Dark Mode is implemented using:

classList.toggle()
